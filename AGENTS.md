# Google Calendar OAuth

- Версии — `MAJOR.MINOR`: `1.1`, `1.2`, `2.0`. Одинаковая версия в manifest, панели, теге и release notes.
- Авторизация Google OAuth через GNOME Online Accounts; без собственного проекта Google Cloud, без Caldir.org relay и без iCloud backend. Не заменять этот способ без запроса владельца.
- Поддерживать русскую и английскую документацию и каталоги `i18n/ru.json` и `i18n/en.json`.
- Проверять manifest, Python/JS tests и UI. Тесты не должны использовать настоящий аккаунт без явного запроса. Скриншоты для публикации — только искусственные события.
- Публикация привязана к полному проверенному SHA. Не добавлять события, токены, GOA bindings, личные пути и конфиги пользователя.
- Сохранять атрибуцию Omarchy, NachoRodriguezM и Caldir. Сборка Google provider выполняется только по закреплённому рецепту и патчу.
